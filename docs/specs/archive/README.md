# Specs Archive

Use this folder for closed planning artifacts that should be preserved for
traceability but no longer belong in the active `docs/specs/` surface.

## Rule

- archive only closed or no-longer-governing specs and batch-card lanes
- keep `docs/specs/` focused on active planning
- preserve enough context that an archived artifact is still understandable
- do not treat archived specs as canonical execution authority once the
  promoted architecture and contract surfaces carry the truth

## Layout

Keep the archive lean:

- `archive/NNN-<slug>.md`

Do not recreate a second complex planning tree here.

## Next Task

active specs surface but still deserve preservation.

# Vision

Vision docs define long-term direction and constraints.
They guide architecture and roadmap decisions without becoming delivery plans.

- `002-<slug>.md`

## Writing rule

- Keep roadmap sequencing and batch detail out of vision docs.
- Update vision when Northstar's long-horizon goals or target operating
  envelopes change.

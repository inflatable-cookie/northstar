Succeeding generation: `g03`

## Generation Intent and Boundary

`g02` was Northstar's external-proof, language-quality, and execution-hardening
generation following the internal foundation work in `g01`. Its boundary
encompassed proving Northstar on external consumer repositories (Signal,
Underlay, Figmatic, Swallowtail, Convergence, Jetstream), establishing strict
execution guardrails, protocol deduplication via the protocol kernel, Rhai
checker migration, modular language-code quality packages (Rust and
TypeScript/Svelte), the orchestrator-thread and worker PR loop, optional Paseo
control-plane integration, parallel-first and economical worker dispatch, and
Chatterbox-led human planning paired with mechanical coordinator execution.

## Shipped Outcomes by Durable Capability

### External consumer repo proof and adoption

Proved the Northstar docs spine, delivery framework, and autonomy guardrails
across external consumer codebases (Signal and Underlay reference cohorts),
proving strict-compliance migration, nested documentation authority, and
workspace container adoption.

### Protocol kernel and canonical documentation deduplication

Consolidated reusable doctrine into `bundle-docs/protocol-kernel.md` and
standard sections. Removed duplicate rules across repo and template surfaces.
Added `effigy check:posture-advisory` for non-blocking drift detection.

### Effigy-native checker migration

Migrated Northstar repository and bundle checkers from TypeScript/Bun to
Effigy-native Rhai scripts (`scripts/check-northstar-*.rhai`, `scripts/lib/*.rhai`),
eliminating unnecessary runtime dependencies from the live verification board.

### Papercuts feedback loop

Introduced the root `PAPERCUTS.md` friction-capture convention, defended by
contract 001 and bundle doctrine, giving agents and humans a standard
low-friction recording surface without interrupting execution.

### Orchestrator thread and worker PR loop

Replaced ad-hoc continuation loops with a formal, file-based
orchestrator/worker PR boundary (`docs/contracts/001-working-rules.md`,
`skills/northstar/references/modes/orchestrator.md`,
`skills/northstar/references/handoff-contract.md`). Established
dependency-frontier parallel-first dispatch, economical worker routing,
lane-local capacity gating, fresh orchestrator continuation, and diversified
model rotation.

### Modular language quality packages

Extracted language-specific audit and authoring capabilities out of the core
Northstar payload into external modular packages under
`docs/contracts/004-language-quality-pack.md`. Shipped the official registry
(`official-registry.json`), provider-neutral Bun lifecycle host
(`language-package-lifecycle.ts`), Rust package (`northstar-rust-quality`), and
TypeScript/Svelte package (`northstar-typescript-quality`) proven through
canary deployments on Jetstream and Convergence. Embedded fallback payloads
were retired.

### Paseo workspace and worktree integration

Integrated Paseo as an optional control plane for dispatch and review: automatic
profile selection, dedicated worktree workspace placement, implicit
injected-tool dispatch, preserved worker parentage, and serial-lease reviewer
placement in the worker workspace.

### Chatterbox-led planning and mechanical coordination

Separated operator-facing semantic planning from automated delivery: Chatterbox
threads hold conversational intake and planning authority, while the coordinator
mechanically executes approved frontiers and gates PR reviews. Added the pre-PR
decision request route for context-complete blocker escalation.

### Review oracles, direct PR review, and intentful instruction surfaces

Established machine-testable review oracles, direct PR review with
provider-native comments, and intent-led agent instruction surfaces
(`docs/contracts/003-agent-instruction-surface.md`).

## Material Migrations, Compatibility Limits, and Retained Risks

- **Checker migration:** Migrated repo checkers from TypeScript/Bun to Effigy
  Rhai scripts (`scripts/check-northstar-*.rhai`).
- **Language package extraction:** Fully extracted language quality logic into
  standalone repositories and registry distribution; embedded payloads removed
  without fallback shims.
- **Paseo runtime:** Replaced ad-hoc worktree commands with managed
  `paseo:worktree` tasks and tool-injected dispatch.
- **Continuous coordinator:** Transitioned orchestrator from monolithic
  conversational sessions to event-bounded mechanical dispatch with Chatterbox
  intake.
- **Retained risks:**
  - Downstream consumer repos adopting modular language packages require
    network/registry connectivity or pre-cached packages.
  - Paseo integration requires connected host daemon when Paseo transport is
    selected; fallback to manual dispatch is preserved.

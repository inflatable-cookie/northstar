## Objective

Prove and freeze the smallest portable installed boundary for TypeScript/Svelte
scope discovery, strict profile resolution, setup, case-local audit recording,
repository-native tool evidence, and the explicit command before production
files are scaffolded.

## Scope

- compare reuse/generalization of the skill-local Effigy/Rhai Rust substrate
  with a TypeScript-specific Rhai implementation;
- reject Bun, Node, npm, pnpm, shell/`jq`, or source-checkout requirements for
  setup, scope, recording, and finalization;
- freeze catalogue, schema, projection, mode, adapter, template, script, record,
  and selector paths;
- freeze root/workspace/nested-package ownership and Svelte/SvelteKit overlay
  resolution;
- freeze repository-native compiler/framework/lint/test evidence records and
  degraded-evidence behavior;
- prove dirty-state and case-local mutation invariants with focused fixtures.

## Acceptance criteria

- [x] no undeclared consumer runtime or Northstar source checkout is required;
- [x] mixed root and nested package fixtures resolve ownership and overlays
  without ancestor leakage;
- [x] setup is deterministically specified as idempotent, preservation-safe, and explicit-only;
- [x] recorder lifecycle binds findings and repair authority before mutation and
  rejects hidden or cross-unit changes;
- [x] unavailable tool evidence cannot become a source pass;
- [x] final paths, selectors, command name, and unsupported claims are frozen.

## Validation

Run focused boundary self-tests, package checks, `effigy qa:docs`, `effigy qa`,
and `git diff --check` after the batch.

## Evidence

Record the evaluated runtime options, chosen boundary, fixture matrix, rejected
alternatives, paths, selectors, dependency floor, and proof output in a bounded
production-boundary report and closeout log.

## Stop conditions

- stop on a new consumer runtime prerequisite or source-checkout dependency;
- stop if generic recorder reuse weakens existing Rust behavior;
- stop if nested ownership or overlay applicability needs operator policy;
- do not scaffold the mode, adapter, or distributed catalogue in this card.

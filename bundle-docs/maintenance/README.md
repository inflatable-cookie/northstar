# Maintenance

This folder is for maintaining Northstar itself, not for normal day-to-day
operator use inside a project.

If you are trying to decide what to do in a live repo, start with
[operators/README.md](/Users/betterthanclay/Dev/projects/northstar/bundle-docs/operators/README.md)
instead.

Use the pages here when you are testing, pruning, or validating the Northstar
operator stack:

- `operator-workflow-drill.md` to run a structured pilot or self-test
- `operator-pilot-record-template.md` to capture real pilot evidence
- `operator-doc-pruning-rubric.md` to decide what to keep, merge, trim, or
  remove after a pilot

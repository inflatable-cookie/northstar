# Source Hubs

Curated source maps organized by feature area.

## Source Hierarchy

1. Official docs, source trees, release notes, specifications
2. First-party technical programs with concrete claims
3. Engineering blogs, staff interviews, conference material
4. Community synthesis pointing back to stronger sources

## Available Source Hubs

- `changelog-source-hub.md` - Changelog formats and generation tools
- `release-management-source-hub.md` - Release automation systems
- `readme-generation-source-hub.md` - README standards and generators
- `documentation-coverage-source-hub.md` - Doc coverage and validation tools

## Source Quality Markers

| Marker | Meaning |
|--------|---------|
| [spec] | Official specification |
| [src] | Source code / official repo |
| [docs] | Official documentation |
| [blog] | First-party engineering blog |
| [talk] | Conference talk or presentation |
| [analysis] | Community analysis with evidence |

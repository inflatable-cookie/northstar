# Northstar Readiness Review

Thin explicit entrypoint for the existing planning-readiness utility.

1. Load `references/router.md` from the main `northstar` skill.
2. Select **Planning readiness review** and load
   `references/modes/planning-readiness-review.md`.
3. Follow that mode's read-only review and single-next-route procedure.
4. Treat the text after `/northstar-readiness-review` as the existing project or
   planning question to assess.

This is a repository-state review, not Atlas-scale strategic planning. Do not
start workers, create worktrees, authorize execution, or merge anything.

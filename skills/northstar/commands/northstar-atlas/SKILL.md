# Northstar Atlas

Thin explicit entrypoint for Northstar's long-horizon planning route.

1. Load `references/router.md` from the main `northstar` skill.
2. Select **Atlas — long-horizon planning** and load
   `references/modes/atlas.md`.
3. Follow the Atlas scale test, horizon model, breadth-first questions,
   promotion map, and stop conditions.
4. Treat the text after `/northstar-atlas` as the project, product, platform,
   or portfolio horizon to shape.

Atlas is plan-only and operator-owned. It is not a readiness audit or a roadmap
compiler. Do not edit production code, start workers, create worktrees,
authorize execution, or merge anything.

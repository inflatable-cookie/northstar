# Northstar Rust Audit

Thin explicit entrypoint for the canonical Rust audit-and-repair route.

1. Load `references/router.md` from the main `northstar` skill.
2. Select **Rust explicit audit-and-repair** and load
   `references/modes/rust-quality-audit.md`.
3. Follow that mode's scope, finding-first record, repair-wave, preservation,
   and completion-evidence contract.
4. Treat text after `/northstar-rust-audit` as the target and requested
   worktree or repository scope.

Do not activate from ordinary Rust coding, broaden repair authority, or mutate
before the recorder contains the local finding and plan.

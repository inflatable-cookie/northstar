# Triage

**Type: REQUIRED** -- A temporary capture buffer for useful observations,
ideas, plans, and questions that are not yet settled into the Northstar docs.

Name notes with the same timestamped format as handoffs:

```text
YYYYMMDD-HHMMSS-<slug>.md
```

Notes are intentionally lightweight Markdown with no required body shape. Read
them during refresh or cleanup, then promote useful content into canonical docs,
merge duplicates, or remove notes that are implemented, superseded, or no
longer useful. Ask the operator when the right destination or removal decision
is unclear. An explicitly open note is temporary; give it a next check or owner
when possible, then promote, implement, or remove it. Triage is not execution
authority.

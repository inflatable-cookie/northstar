# Handoffs

**Type: REQUIRED** -- Keep this folder when using the minimal Northstar starter.

The handoff skill writes fresh-thread notes here when another thread genuinely
needs to take over. It uses filenames like:

```text
YYYYMMDD-HHMMSS-<slug>.md
```

Handoffs are separate from `logs/`: logs record evidence, while handoffs help
the next person or agent understand the story and choose the next move.
